wp-theme — WooCommerce edition

- Timber 2.x and Twig storefront templates
- WooCommerce: shop, products, cart, checkout, account and emails
- Polylang-aware theme context
- Vite 6 and Lightning CSS asset pipeline
- PHP 8.2–8.5 and WordPress 6.9+

Quick start:
- Install and activate WooCommerce and Polylang Pro
- composer install
- npm ci
- npm run build

See README.md for complete setup, Carbon Fields/Twig examples and deployment instructions.
